# Changelog

## 1.0.0 — 2026-10-22

- Detect installed Photoshop versions and accept additional executable paths.
- Register independent PSD/PSB candidates and per-user application capabilities.
- Preserve Windows default choices and open Settings for user selection.
- Back up each changed registry value, with conflict-aware restoration.
- Remove ambiguous Photoshop.exe legacy history without clearing other apps.
- Add a bilingual launcher, documentation and Windows PowerShell 5.1 / 7 tests.
- Add optional independent desktop-context execution for diagnostics and repair.
